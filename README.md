# Rubber Band Text Editor

This simple JavaScript text editor allows you to mark multiple rectangular blocks of text and delete them.

It is really handy if you need to delete a column of text in a text file quickly and easily. Normally you would need to edit each line. Not so here. Highlight multiple blocks of text you want to delete, and hit the delete button.

Try it: https://vpelss.github.io/RubberbandTextEditor/
